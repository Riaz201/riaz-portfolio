# Riaz Jamali - Professional IT Portfolio

A simple, responsive portfolio website built with HTML, CSS, and JavaScript for the University of Sindh Professional IT Portfolio activity.

## Sections included

- Home / Hero
- About Me
- Career Objective
- Education
- Technical Skills
- Projects Portfolio
- Project Case Study
- Academic Experience
- Certifications / Ongoing Learning
- Achievements placeholder
- CV
- Professional Profiles
- Contact
- Navigation and Footer

## Run locally

Open `index.html` directly in a browser, or run a local server:

```powershell
python -m http.server 5500
```

Then visit `http://localhost:5500`.

## Deploy

This project can be deployed directly to Netlify or Vercel. Use the repository root as the publish directory.

## Personalization

Replace `Riaz-CV.pdf` with a real PDF, and update the GitHub and LinkedIn links when those profiles are available.

## Simple project demos

- `projects/task-manager/` - a task list that supports add, complete, delete, and browser local storage
- `projects/task-distributor/` - a visual two-node task distribution simulation

## File structure

- `index.html` - Portfolio content and semantic page structure
- `styles.css` - Responsive layout, theme, and component styles
- `script.js` - Mobile navigation and footer behavior
- `Riaz-CV.pdf` - Downloadable curriculum vitae
- `projects/task-manager/` - Simple study task manager demo
- `projects/task-distributor/` - Simple distributed task simulator demo
